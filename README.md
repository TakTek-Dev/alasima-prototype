# Al-Asima — editorial redesign prototype

Interactive design prototype for «العاصمة» (Al-Asima News Network), a Jerusalem-focused Arabic news outlet.
Static HTML, CSS and vanilla JavaScript, right-to-left, no build step.

**Every news item, figure and name in these pages is illustrative.** This is a design prototype, not a published news site.

## Pages

| Page | What it shows |
| --- | --- |
| `index.html` | Design direction and system: brand analysis, tokens, components, AI editorial policy, audit log |
| `home.html` | Front page |
| `jerusalem.html` | «مدار القدس», the Jerusalem hub and its orbit map |
| `article.html` | Article |
| `live.html` | Live coverage |
| `cms.html` | AI-assisted editorial desk, with an editor approving every step |
